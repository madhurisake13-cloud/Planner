# Planner

An anime-themed To-Do List web application built using HTML, CSS, and Vanilla JavaScript.

This project allows users to manage daily tasks with a modern UI, progress tracking, task filtering, and dynamic interactions.

---

## Features

- Add new tasks
- Delete tasks
- Edit existing tasks
- Mark tasks as completed
- Progress bar with completion percentage
- Task statistics (Total, Completed, Pending)
- Filter tasks:
  - All
  - Completed
  - Pending
- Responsive design for mobile and desktop
- Anime-inspired dark neon interface
- Smooth animations and hover effects
- Enter key support for adding tasks

---

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome Icons

---
## Conclusion

This project demonstrates the development of a responsive and interactive To-Do List web application using HTML, CSS, and Vanilla JavaScript. It highlights important front-end development concepts such as DOM manipulation, event handling, dynamic rendering, and responsive UI design.

The application provides users with an efficient way to manage daily tasks through features like task creation, editing, deletion, filtering, and progress tracking. The anime-inspired interface enhances the visual appeal while maintaining usability and performance.

Overall, this project helped strengthen practical JavaScript skills and improved understanding of building dynamic web applications without using external frameworks.
